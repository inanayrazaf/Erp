# Veloce ERP Mada V6.9

Déployer le contenu de cette archive directement sur Netlify.

V6.9 ajoute une comptabilité générale par business basée sur le PCG 2005 malagasy : journal, grand livre, balance, bilan, compte de résultat, flux de trésorerie, capitaux propres, annexe, plan de comptes et écritures manuelles.

Les données restent locales dans IndexedDB. Le Service Worker est versionné `veloce-v690`.

Référentiel officiel : PCG 2005 du Ministère des Finances / Conseil Supérieur de la Comptabilité de Madagascar.
